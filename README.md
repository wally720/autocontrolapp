# autocontrolapp
aplicacion de gastos vehiculares
Esta aplicación te permite llevar un registro detallado de los gastos asociados a tus vehículos. Podrás gestionar:

*   **Carga de combustible:** Registra cada vez que llenes el tanque, incluyendo el costo, la cantidad de litros y el kilometraje.
*   **Mantenimientos:** Anota los servicios realizados a tu vehículo, como cambios de aceite, revisiones, reparaciones, etc.
*   **Otros gastos:** Cualquier otro gasto relacionado con el vehículo, como peajes, lavados, estacionamientos, etc.

Con `autocontrolapp` podrás tener un control claro de cuánto gastas en tu vehículo y optimizar tus finanzas.
