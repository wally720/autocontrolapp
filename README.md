# Auto Gasto PRO
aplicacion de gastos vehiculares
Esta aplicación te permite llevar un registro detallado de los gastos asociados a tus vehículos. Podrás gestionar:

*   **Carga de combustible:** Registra cada vez que llenes el tanque, incluyendo el costo, la cantidad de litros y el kilometraje.
*   **Mantenimientos:** Anota los servicios realizados a tu vehículo, como cambios de aceite, revisiones, reparaciones, etc.
*   **Otros gastos:** Cualquier otro gasto relacionado con el vehículo, como peajes, lavados, estacionamientos, etc.

Con `Auto Gasto PRO` podrás tener un control claro de cuánto gastas en tu vehículo y optimizar tus finanzas.

 ## 🔐 Política de Privacidad

Este proyecto se toma en serio la privacidad de los usuarios. A continuación, se detalla el manejo de la información:

### 1. Información Recopilada
La aplicación solo solicita el **correo electrónico** con el único fin de crear una cuenta de usuario y permitir el acceso privado a sus registros personales de gastos vehiculares.

### 2. Uso de la Información
La información recopilada se utiliza exclusivamente para:
* **Autenticación:** Identificar al usuario al iniciar sesión.
* **Sincronización:** Vincular los registros de gastos a la cuenta específica del usuario.
* **Privacidad:** No se comparten ni venden datos a terceros.

### 3. Seguridad y Almacenamiento
* **Infraestructura:** Los datos se almacenan en **Firebase (Google)** bajo estándares de seguridad industriales.
* **Conexión:** El sitio se sirve mediante **GitHub Pages** utilizando cifrado HTTPS.

### 4. Control de Datos
Los usuarios tienen control total sobre sus datos. Si deseas eliminar tu información, puedes hacerlo desde la configuración de la app o abriendo un *issue* en este repositorio.
